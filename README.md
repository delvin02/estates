# Estates

Estates is a real estate and Domain scraper built to analyse Adelaide housing trends from 2022–2024. The project includes data collection, market trend analysis, visualisation, and machine learning models for housing price prediction across Adelaide suburbs.

The repository explores housing growth patterns, affordability changes, suburb-level insights, and predictive analytics using real-world property listing data.

## Features

* Realestate & Domain property scraping
* Adelaide housing market trend analysis
* Data visualisation & suburb heatmaps
* Machine learning housing price prediction
* Jupyter/Google Colab workflows
